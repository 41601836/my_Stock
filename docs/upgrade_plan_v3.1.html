1A 因子中性化引擎 — 行业 + 市值双重残差化 新建

目标：每个因子在截面回归中剥离 对数自由流通市值和 申万一级行业虚拟变量，仅保留残差 ε 作为纯净 Alpha。

数学：

Factor_raw = β_size × ln(free_mv) + Σ β_ind × Industry_i + ε # ε = neutralized factor（纯净 Alpha）

实现：

  • 新建 factor_lib/neutralizer.py — 核心中性化引擎
  • 截面回归用 statsmodels.OLS，按每个交易日独立拟合
  • 残差写入新表 factor_values_neutral（不覆盖原表）
  • 行业分类从 stock_list.industry 获取（已有）
  • 自由流通市值从 Tushare daily_basic 获取（需新增数据拉取）

关键函数设计：

class FactorNeutralizer: def neutralize(self, factor_df, date): # 1. 取当日截面: [ts_code, factor_value, ln_free_mv, industry] # 2. 构造 X = [ln_free_mv, industry_dummies] # 3. OLS: y = Xβ + ε # 4. 返回残差 ε 作为 neutralized factor # 5. 标准化残差: (ε - mean) / std def batch_neutralize(self, factor_names, start_date, end_date): # 按交易日循环，批量产出 factor_values_neutral 表

1B 因子池正交化 — 对称正交（Symmetric Orthogonalization） 新建

目标：消除同组因子的多重共线性，避免在同一风险因子上重复加杠杆。

方法：对动量组、流动性组、聪明钱组分别做对称正交化

# 对称正交化: F_orth = F × (F'F)^{-1/2} # 保持因子均值和方差不变，仅消除组内相关性 import numpy as np from scipy.linalg import sqrtm def symmetric_orthogonalize(F): # F: (N_stocks, K_factors) 矩阵 cov = F.T @ F / (F.shape[0] - 1) F_orth = F @ np.linalg.pinv(sqrtm(cov)) return F_orth.real

因子分组：

组别当前因子正交化后效果
动量/反转return_5d, return_20d, return_120d, excess_return_20d消除中期/短期动量共线
流动性turnover_rate, turnover_rate_5d, turnover_rate_20d, vol_ratio消除换手率族共线
聪明钱/微观north_net_inflow_ratio, chip_concentration, profit_ratio_estimate消除筹码类共线

2A 隔夜收益与日内收益分离 新建 情绪维度

逻辑：A股"散户推动隔夜开盘、机构量化主导日内博弈"。隔夜跳空与日内动量的信息含量截然不同。

# 隔夜收益: T 日收盘 → T+1 日开盘 overnight_return = open(t+1) / close(t) - 1 # 日内收益: T+1 日开盘 → T+1 日收盘 intraday_return = close(t+1) / open(t+1) - 1 # 衍生因子: 5日隔夜均值 / 5日日内均值 / 隔夜-日内分离度 overnight_mean_5d = mean(overnight_return, 5) intraday_mean_5d = mean(intraday_return, 5) overnight_intraday_gap = overnight_mean_5d - intraday_mean_5d

注册因子：overnight_return_5d（反向，隔夜高的散户情绪过热）、intraday_momentum_5d（正向，日内机构博弈方向）

四重共振 · 情绪维度
隔夜收益直接反映散户情绪（集合竞价跳空），是"情绪"维度的微观特征。当隔夜收益极高 + 换手率分位 > 0.8 → 情绪高潮信号 → 触发卖出铁律①。
2B Amihud 非流动性 + 成交额波动率 + 成交量偏度 新建 资金维度

Amihud 非流动性：衡量"每单位成交额推动的价格位移"

amihud_illiq_20d = mean(|daily_ret| / daily_amount, 20) # 值越大 = 流动性越差 = 价格冲击成本越高

成交额波动率：捕捉筹码锁仓与恐慌抛售的分歧度

turnover_volatility_20d = std(turnover_rate, 20) # 高波动 = 筹码松动，多空分歧加大

成交量偏度：识别放量方向的不对称性

volume_skewness_20d = skew(daily_volume, 20) # 正偏 = 放量上涨多于放量下跌（资金净流入） # 负偏 = 放量下跌为主（资金出逃）

注册因子：amihud_illiq（反向）、turnover_volatility（反向）、volume_skewness（正向）

四重共振 · 资金维度
Amihud + 成交量偏度组合替代原始 vol_ratio，形成"资金微观冲击"复合信号。当 Amihud 飙升 + 偏度转负 → 资金持续流出 → 触发卖出铁律②。
2C Garman-Klass 高阶波动率估计器 新建 资金维度

逻辑：基于 High/Low/Close/Open 的 GK 估计器比收盘价标准差统计效率高 5-8 倍。

# Garman-Klass 波动率 (年化) sigma_gk = sqrt( (1/n) × Σ [ 0.5 × (ln(H/L))² - (2×ln2 - 1) × (ln(C/O))² ] ) × sqrt(252)

注册因子：gk_volatility_20d（反向，替代现有 volatility_20d）

2D CYQ 筹码分布模型 — 真实浮盈比例与上方抛压 新建 筹码维度

逻辑：摒弃"均线绝对偏离"的简陋做法，用指数衰减换手率加权计算筹码持仓成本分布（CYQ 模型）。

# CYQ 筹码成本分布模型 # 1. 对过去 K 日（如 60 日），按换手率指数衰减加权 decay_factor = exp(-lambda × day_offset) # lambda = 衰减系数 weight_t = turnover_rate(t) × decay_factor # 2. 每日成交价近似为当日 VWAP（或 (H+L+C)/3） price_t = (high + low + close) / 3 # 3. 加权构建成本分布直方图 → 形成筹码峰 cost_distribution = weighted_histogram(price_t, weight_t) # 4. 计算衍生指标 profit_ratio = sum(weights[price < current_price]) / total_weight upper_pressure = sum(weights[price > current_price]) / total_weight chip_peak_price = argmax(cost_distribution)

注册因子：cyq_profit_ratio（反向，浮盈比例高→抛压大）、cyq_upper_pressure（反向）

文件：新建 src/cyq_model.py — 筹码分布核心算法

四重共振 · 筹码维度
CYQ 模型替代当前简陋的 chip_concentration（均线偏离），直接输出"多少筹码在当前价以下"（浮盈比例）和"上方有多少套牢盘"（抛压阻力）。浮盈比例 > 0.85 = 筹码分散 → 触发共振弱化信号。

3A MVO 组合优化器 — 凸优化求解最大 IC/IR 新建

目标：替代当前等权 + max_weight 硬上限的朴素方案。

# 优化目标: 最大化预期超额收益 max μ' w s.t. Σ w_i = 1 # 权重和=1 w_i ≤ max_weight # 单股上限 30% |w_ind - w_ind_bench| ≤ 0.05 # 行业偏离 ±5% turnover(w, w_old) ≤ 0.5 # 换手率惩罚 w_i ≥ 0 # 非负

  • 行业基准权重 = 沪深300 行业占比（或全市场自然权重）
